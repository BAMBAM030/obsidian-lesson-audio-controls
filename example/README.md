# Beispielordner

Die Beispiel-Lektion demonstriert ausschließlich die portable Verlinkung. Eine Beispiel-MP3 ist absichtlich nicht enthalten.

Lege für einen echten Test deine eigene Audiodatei hier ab:

```text
example/Audio/beispiel-dialog.mp3
```

Danach zeigt die Datei `beispiel-lektion.md` den eingebetteten Player, die Wiederholung und — bei aktiviertem Plugin — die Tempo- sowie Wiederholungssteuerung.
